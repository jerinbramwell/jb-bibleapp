# Daily devotionals — Henry's original English

`en.json` maps each devotional date (YYYY-MM-DD) to Matthew Henry's original English words that the app's
Malayalam devotional reflection was translated from (1706, public domain):

```json
{ "2026-10-29": { "reflectionEn": "...", "sourceEn": "Matthew Henry, Concise Commentary (Proverbs 3:1-6)" } }
```

Used when the app's primary language is English. `prayerEn` appears only where Henry's own text includes a
prayer (2026-11-03). " ... " marks for skipped sentences are removed, as in the Malayalam.
The four earliest devotionals (2026-10-25 to 2026-10-28) have no Henry source and are not included.
